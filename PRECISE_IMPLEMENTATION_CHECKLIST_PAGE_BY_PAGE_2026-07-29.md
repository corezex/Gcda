---

## How to use this checklist

This checklist is intentionally practical.

Each page or page-template includes:
- **Current role** on the site
- **Primary keyword intent** already served
- **Gap type**
  - `None` = already aligned
  - `Tighten` = existing page is right, keyword framing needs improvement
  - `Expand` = existing page should add more sections/FAQ/tables
  - `New page later` = only if existing page optimization is not enough
- **Exact implementation tasks**
- **Priority**

# Decision rule to avoid false expansion
Before creating any new page, ask:

- [ ] Is this keyword already served by an existing page?
- [ ] Can title/H1/H2/FAQ/table optimization capture it first?
- [ ] Would a new page be genuinely unique?
- [ ] Would the new page reduce cannibalization or create it?

If the answer is “existing page can own it,” optimize first.
If the answer is “existing page cannot naturally absorb the intent,” then create the new page.
